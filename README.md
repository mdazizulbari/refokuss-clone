# Refokuss Clone
A clone of the Refokuss website, built to hone my frontend skills with a focus on modern design and interactivity. This project, inspired by Sheryians Coding School, emphasizes clean code and engaging user experiences.

## 🌐 Live Project
[View Refokuss Clone Live](https://refokuss-clone.vercel.app)

## 🛠 Technologies Used
- **Frontend**: HTML, CSS, JavaScript (ES6)
- **Libraries**: GSAP, ScrollTrigger
- **Tools**: Git, npm

## ✨ Core Features
- **Interactive Animations**: GSAP and ScrollTrigger for scroll-based animations.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Modern UI**: Sleek, professional design inspired by Refokuss’s aesthetic.
- **Clean Code**: Modular and maintainable JavaScript structure.

## 🚀 How to Run Locally
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/mdazizulbari/refokuss-clone.git
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd refokuss-clone
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Serve the Project**:
   - Use a local server (e.g., Live Server extension in VS Code) or run:
   ```bash
   npx serve
   ```
5. Open the provided local URL (e.g., `http://localhost:3000`) in your browser.
